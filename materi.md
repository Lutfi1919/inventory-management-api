## apa itu node / node runtime?
```
Wadah untuk komputer kita agar bisa menjalankan javascript
```

## apa itu npm?
```
package manager, yg fungsinya untuk memasang, mengupdate dan menghapus package dari orang lain
```

## package.json dan package.lock.json
```
package.json : file yang isinya info project tsb, script, dependencies dan devDependencies

package.lock.json : file untuk ngunci versi modul yg dipakai supaya sama persis di semua komputer
```

## dependencies vs devDependencies
```
dependencies : modul yg dibutuhkan oleh user agar aplikasi berjalan

devDependencies : modul yg dibutuhkan selama proses development
```

## npm scripts
```
semua script perintah yang dipakai, ada didalam package.json bagian scripts
```

## node modules
```
folder yg otomatis di generate saat npm install, untuk menampung library, modul, dan dependencies yang di install
```
